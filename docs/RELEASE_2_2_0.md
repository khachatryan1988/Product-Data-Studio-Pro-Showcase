# Product Data Studio Pro 2.2.0

## English and Russian interface

Version 2.2.0 supports both English and Russian. Users can switch languages from the application menu without restarting the program.

The selected language is saved locally and restored the next time the application starts.

## Responsive interface

The main workspace toolbars were reorganized to prevent long Russian labels from being clipped on common Windows screen sizes.

## Distribution

The commercial product is delivered as a ZIP file containing a Windows installer:

```text
Product_Data_Studio_Pro_2.2.0.zip
└── ProductDataStudioPro_Setup.exe
```

The commercial download does not require Python or PyCharm.
