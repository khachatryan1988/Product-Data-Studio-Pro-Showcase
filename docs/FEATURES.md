# Feature Overview

## Catalog preparation
Import Excel or CSV, map columns, clean whitespace, normalize SKU values, remove
blank rows, detect invalid prices, and generate a detailed audit report.

## Validation
Use standard checks, smart validation, and reusable custom rules to identify
missing data, duplicate SKUs, suspicious category values, malformed image URLs,
and values pasted into the wrong columns.

## Catalog operations
Compare old and new versions, merge supplier updates, combine multiple catalogs,
split large catalogs, and apply reusable transformation recipes.

## Batch workflows
Audit, repair, manually review, and publish multiple catalogs in a single workflow.

## Marketplace output
Generate Shopify and WooCommerce CSV files with review controls that exclude
blocked products from the final export.
