# Privacy Policy — Product Data Studio Pro

**Effective date:** 31 July 2026  
**Version:** 2.1.0 RC1

Product Data Studio Pro is designed as a local desktop application.

## Data processing

- Excel and CSV catalogs are opened and processed on the user's computer.
- The application does not upload catalog contents to a Product Data Studio server.
- The application does not include advertising, analytics, telemetry, account login, or cloud synchronization.
- Exports are written only to locations selected by the user.

## Local files

The application may create local output files, reports, JSON profiles, recipes, and crash logs. Crash logs are stored in the user's local application-data folder and contain technical error details. They are not transmitted automatically.

Typical Windows log location:

`%LOCALAPPDATA%\ProductDataStudioPro\logs`

## Third-party platforms

Shopify and WooCommerce CSV files are generated locally. Uploading those files to a marketplace is a separate action performed by the user and is governed by that platform's privacy terms.

## User responsibility

Users should maintain backups and avoid placing unnecessary personal or confidential information in product catalogs. The user is responsible for compliance with applicable data-protection laws.

## Contact

Use the support contact stated on the purchase page or receipt.
